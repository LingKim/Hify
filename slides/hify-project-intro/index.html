核心链路 Product Flow

产品主线不是“功能堆叠”，而是跑通单 Agent 闭环

  • 管理员维护模型 Provider，确保平台知道“可以调用哪些模型”。
  • 用户创建 Agent，绑定默认模型，并配置提示词、欢迎语、运行参数。
  • 会话模块加载 Agent 配置，校验模型，拼装上下文并调用 LiteLLM。
  • 知识库和工具作为后续增强能力，挂到 Agent 配置与会话运行层。
  • 对话日志、运行记录和错误状态落库，支撑可观测性与复盘。

开发路线 Roadmap

按依赖推进，而不是按功能名平均铺开

1

模型与 Agent

Provider 管理稳定后，Agent 成为可保存、可预览、可绑定的配置主体。

2

对话运行

打通 Web 对话、SSE 流式输出、消息历史、运行记录与错误落库。

3

知识与工具

接入 RAG 检索和外部 API 工具，让 Agent 从回答走向行动。

4

发布与部署

补齐 API 集成、日志分析、团队权限、Workflow 和 Docker Compose 交付。
