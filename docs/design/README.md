# Hify 设计文档

这个目录用于长期维护 Hify 的产品与技术设计文档，不是一次性交付物。

当前约定：

- 方案设计文档：描述背景、目标、边界、核心设计取舍
- 数据库设计文档：描述实体关系、字段含义、约束与迁移策略
- 接口文档：描述请求响应、错误码、聚合视图与前后端约束
- 前端文档：描述页面信息架构、交互模型、状态边界与联调约定

维护规则：

- 每个功能模块尽量维护在独立子目录下
- 设计变更时，优先更新文档，再更新实现
- 文档中的接口与数据结构应以当前主干代码为准
- 文档允许分阶段完成，但不能长期留空白标题

当前模块：

- `auth/`：登录、JWT 鉴权与前端登录态闭环
- `provider-management/`：LLM 模型提供商管理模块
- `user-management/`：内部账号管理模块
- `conversation/`：会话与对话运行模块
- `agent-configuration/`：Agent 配置模块
- `knowledge/`：知识库、文档处理、检索测试与 RAG 注入模块
- `tool/`：HTTP 工具管理、OpenAPI 导入与测试执行模块
- `agent-tool-runtime/`：Agent 工具绑定到对话运行时的调用闭环
- `mvp-roadmap/`：MVP 功能清单对应的整体开发计划
